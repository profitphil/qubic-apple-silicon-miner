# Reference sources — attribution

`qubic-core-mining/` contains **unmodified** headers copied from the official
[qubic/core](https://github.com/qubic/core) repository (`src/mining/`), reproduced here
solely as the authoritative reference for the BPP9000 scoring semantics and the AVX-512
batching strategy that informed the Metal port.

Copyright and license of these files belong to the qubic/core authors under that
repository's license. If the Qubic team prefers these be referenced by URL/commit instead
